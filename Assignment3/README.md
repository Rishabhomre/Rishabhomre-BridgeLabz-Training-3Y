# Assignment 3 – JavaScript

This folder contains one JavaScript file for each question.

## Files
- `Q1_Dynamic_Data_Parser.js`
- `Q2_Employee_Bonus_Calculator.js`
- `Q3_Transaction_Validator.js`
- `Q4_Debugging_Mystery.js`
- `Q5_Hoisting_Lab.js`
- `Q6_Pyramid_Pattern_Generator.js`
- `Q7_Smart_Calculator.js`
- `Q8_Strict_Mode_Showdown.js`
- `Q9_JSON_Audit.js`
- `Q10_Nested_Hoisting_Closures.js`

## Run the files
1. Extract/open this folder in VS Code.
2. Open a terminal in the folder.
3. Run one file at a time, for example:

   `node Q1_Dynamic_Data_Parser.js`

4. Repeat with the other file names.

No external libraries are required. Each file uses `console.log()` for output.

## Debugging exercises
For Q3, Q4, Q6, Q9, and Q10, add breakpoints at the comments provided in the source.
In VS Code, use **Run and Debug**, then inspect **Variables**, **Watch**, and **Call Stack**.
