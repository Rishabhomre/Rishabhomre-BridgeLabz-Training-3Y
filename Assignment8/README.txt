How to run:
1. Install Node.js if it is not already installed.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run any task using:
   node Q1_Student_Result.js
   node Q2_Online_Food_Ordering.js
   ...
   node Q9_Fitness_App_Analytics.js

Each file is independent and contains its own test data and console output.

Notes:
- Q1 uses 80/60/40 as grade boundaries for A/B/C/F.
- Q5 uses a sample fare formula: Rs.30 base fare + Rs.12 per km.
- Q6 considers stock below 5 as low stock.
