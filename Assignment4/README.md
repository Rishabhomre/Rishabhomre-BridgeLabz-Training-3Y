# Assignment 4 — JavaScript (ES6+)

This folder contains all 9 completed tasks. Each question has its own JavaScript file.
HTML-based tasks also include their own HTML and CSS files.

## How to run
1. Extract this folder.
2. For browser tasks, open the matching `.html` file in a browser.
3. For JavaScript-only tasks, open a terminal in this folder and run `node Q1_ProductManager.js`, `node Q3_LibraryManagement.js`, or `node Q6_EmployeeManagement.js`.
4. Q9 includes both a Node.js version and a browser demo.
