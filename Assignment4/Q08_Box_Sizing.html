Box-Sizing Comparison

Both examples declare the same CSS width and padding.

content-box

CSS width: 260px

Padding: 24px

Border: 6px

Total rendered width: 320px

border-box

CSS width: 260px

Padding: 24px

Border: 6px

Total rendered width: 260px

What changes?

With content-box, the declared width covers only the content, so padding and borders are added outside it. With border-box, the declared width includes content, padding, and border.

Predictable sizing makes responsive layouts easier to build.
