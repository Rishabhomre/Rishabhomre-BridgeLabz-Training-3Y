Assignment 9 – jQuery Practical

What is jQuery?

jQuery is a JavaScript library that simplifies DOM manipulation and events.

Is jQuery free?

Yes. jQuery is open-source and free to use.

Can jQuery work with HTML5?

Yes. It works with modern HTML5 documents.

What does an event handler do?

It runs code when a user action, such as a click, occurs.

How do I select an element?

Use a jQuery selector such as $('#id') or $('.class').
