ASSIGNMENT 5 - HTML AND CSS

Folder name: Assignment5_HTML_CSS

This folder contains 10 HTML files and 10 matching CSS files (one pair per question).

How to use:
1. Extract Assignment5_HTML_CSS.zip.
2. Open the folder in VS Code.
3. Keep each HTML file next to its matching CSS file.
4. Open an HTML file in your browser, or use Live Server if installed.

Requirements:
- No JavaScript or external framework is used.
- Semantic HTML, comments, responsive CSS, gradients, positioning, flexbox/grid, and form styling are included where required.
- Some sample images are hosted online, so internet access is needed to load them.
- Replace example email, phone, profile photo, or other sample details with your own information before submitting.
