ASSIGNMENT 10 — BOOTSTRAP 5

This folder contains 10 complete responsive Bootstrap examples. Each question has its own HTML file and matching CSS file with descriptive names.

How to run:
1. Extract the ZIP folder.
2. Open any numbered .html file in a modern browser.
3. Internet access is required for Bootstrap CDN, Google Fonts (Question 5), and remote Unsplash images.
4. Bootstrap's JavaScript bundle is included only on pages that use Bootstrap interactive components (navbar collapse or dismissible alert / carousel).
