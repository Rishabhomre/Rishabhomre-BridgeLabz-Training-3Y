Responsive CSS Cheat Sheet

Four essential concepts for layouts that work across screens.

Filters

Adjust the appearance of images and other elements.

filter: grayscale(100%);

Media Queries

Apply CSS rules only when a viewport matches a condition.

@media (max-width: 700px) { ... }

Responsive Design

Let layouts adapt to available width and device capabilities.

width: min(100%, 60rem);

Typography

Use fluid font sizes while keeping readable limits.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Build two-dimensional layouts with flexible tracks.

grid-template-columns: repeat(auto-fit, minmax(15rem, 1fr));

Flexbox

Align items in a row or column with flexible spacing.

display: flex; gap: 1rem;
