ASSIGNMENT 5 — JavaScript ES6+

Files:
- Q1_callback_greeting.js — callback flow
- Q2_apply_operation.js — callback operations on arrays
- Q3_arrow_function_this.js — arrow function `this` vs normal method
- Q4_car_prototype.js — shared prototype method
- Q5_person_student_prototype.js — constructor/prototype inheritance
- Q6_person_faculty_professor_chain.js — multi-level prototype chain
- Q7_closure_multiplier.js — closures
- Q8_array_myMap.js — custom Array.prototype.myMap()
- Q9_class_inheritance.js — class inheritance with extends and super()

How to run:
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run one file at a time, for example:
   node Q1_callback_greeting.js

Each JavaScript file is independent and includes comments and example output.
