Responsive Design Principles

Three foundations for flexible and accessible web pages.

Fluid Layouts

Use flexible widths so content can adapt to the available space.

.container {
  width: min(100% - 2rem, 70rem);
  margin-inline: auto;
}

Flexible Media

Make images and video fit inside their containers without distortion.

img, video {
  max-width: 100%;
  height: auto;
}

Breakpoints

Adjust layout only when the content needs a different arrangement.

@media (max-width: 600px) {
  .layout { grid-template-columns: 1fr; }
}

Responsive layouts begin with flexible foundations.
