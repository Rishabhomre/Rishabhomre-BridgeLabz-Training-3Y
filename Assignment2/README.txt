ASSIGNMENT 2 - HTML

This folder contains 20 separate HTML files, one for each assignment task.

How to use:
1. Extract Assignment2_HTML.zip.
2. Open the Assignment2_HTML folder in VS Code.
3. Open any .html file.
4. Right-click the file and choose Open with Live Server (if installed), or open it directly in a browser.

Requirements followed:
- Every HTML file has <!DOCTYPE html>, a meaningful title, and comments where useful.
- HTML only: no CSS and no JavaScript.
- The name used in examples is Rishabh Singh.
- Q3 uses a remotely hosted Doraemon image; an internet connection is required to display it.
