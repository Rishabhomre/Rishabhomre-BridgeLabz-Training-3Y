ASSIGNMENT 3 - HTML

Folder: Assignment3_HTML
Contains 15 separate HTML files, one for each question.

How to use:
1. Extract Assignment3_HTML.zip.
2. Open the Assignment3_HTML folder in VS Code.
3. Open any .html file in a browser, or use Live Server if installed.

Notes:
- HTML only: no CSS or JavaScript is used.
- Each HTML file includes <!DOCTYPE html>, language, charset, viewport, and a meaningful title.
- Contact details, institute names, sample company/news content, and some example data are placeholders. Update them before submitting if needed.
- Product/travel placeholder images require an internet connection.
